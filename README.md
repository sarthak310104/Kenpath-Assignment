# Sweety - Blood Glucose Tracker

A small web app where a diabetes patient records up to 4 blood glucose readings a day and views daily, month-to-date and monthly reports.

Stack: Node.js + Express, PostgreSQL, React (Vite).

## Features

- Sign up and log in (bcrypt-hashed passwords, JWT auth)
- Add, view, edit and delete readings (4 slots per day, value in mg/dl)
- Validation with clear error messages
- Daily, month-to-date and previous-month reports (highest, lowest, average, count)

## Project structure

```
sweety/
  server/   Express API, PostgreSQL access, tests
  client/   React frontend
```

## Prerequisites

- Node.js 18+
- PostgreSQL 14+
- Git
